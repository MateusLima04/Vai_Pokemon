## 🐲 VaiPokemon

O **VaiPokemon** é uma aplicação híbrida desenvolvida com **Angular 20**, **Ionic 8** e **TypeScript**, que utiliza a **PokéAPI** para criar uma experiência interativa de batalhas Pokémon em tempo real.

O projeto foi desenvolvido com o objetivo de demonstrar conhecimentos em **desenvolvimento frontend moderno**, **integração com APIs REST**, **arquitetura modular** e **criação de interfaces responsivas**, transformando dados complexos em uma experiência intuitiva e dinâmica para o usuário.

Além do sistema de batalhas, a aplicação também funciona como uma **Pokédex interativa**, permitindo explorar informações detalhadas dos Pokémons, como tipos, estatísticas, habilidades, dimensões e movimentos.

---

##  Funcionalidades

###  Sistema de Batalhas

* Geração aleatória de confrontos entre Pokémons;
* Consumo de dados em tempo real através da PokéAPI;
* Cálculo de dano baseado nos atributos oficiais de Attack e Defense;
* Determinação automática do vencedor;
* Tratamento de cenários de empate.

### Pokédex Interativa

* Exibição detalhada das informações dos Pokémons;
* Visualização de tipos, habilidades e movimentos;
* Informações de altura, peso e estatísticas;
* Imagens oficiais fornecidas pela PokéAPI.

### Experiência do Usuário

* Interface moderna e intuitiva;
* Barras dinâmicas para exibição dos atributos;
* Feedback visual durante carregamentos;
* Efeitos de interação implementados com diretivas customizadas;
* Design responsivo para dispositivos móveis e desktop.

## Arquitetura

O projeto segue uma arquitetura modular baseada na separação de responsabilidades:

* **Services:** comunicação com a API e regras de negócio;
* **Pages:** gerenciamento das telas da aplicação;
* **Components:** componentes reutilizáveis e desacoplados;
* **Directives:** comportamentos visuais personalizados;
* **Pipes:** formatação e transformação de dados;
* **Lazy Loading:** carregamento otimizado das rotas.

## Objetivo do Projeto

O VaiPokemon foi desenvolvido para consolidar conhecimentos em Angular, Ionic e TypeScript, explorando integração com APIs externas, lógica de programação, desenvolvimento de interfaces modernas e aplicação de boas práticas de engenharia de software na construção de aplicações escaláveis e performáticas.
